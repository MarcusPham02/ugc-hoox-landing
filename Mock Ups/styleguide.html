UGC Hoox — Color & Layout Style Guide

Directional only. The Pinterest pin's actual pixels can't be read programmatically — these two palettes are clean, slick interpretations of the cool/modern brief, not literal extractions.

Tokens-only. Each color maps to an existing main.css variable name, so migrating the chosen option later is a value swap — no CSS refactor. Nothing here touches the live index.html or main.css.
